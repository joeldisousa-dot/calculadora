ℹ️ Observações sobre o cálculo

1. Base de cálculo: o sistema utiliza a base oficial informada pelo usuário quando disponível. Caso contrário, utiliza a base calculada a partir dos valores informados.

2. Percentual: cada contrato é calculado individualmente utilizando o percentual informado para aquele contrato.

3. Fórmula: desconto teórico = base de cálculo × percentual ÷ 100.

4. Saldo devedor: quando informado, o desconto final fica limitado ao saldo devedor do respectivo contrato.

5. Limite: a calculadora verifica se a soma dos percentuais informados ultrapassa 35%.

6. Conferência: esta ferramenta é destinada à conferência e simulação. A apuração definitiva deve considerar os dados oficiais disponibilizados pelos sistemas competentes e as regras legais aplicáveis ao caso.
