Valor teórico do contrato = Base de cálculo × Percentual de garantia.
Valor efetivo conferido = menor entre o valor teórico e o saldo devedor atualizado.

4. Como o cálculo é feito

Passo 1 — Percentual do contrato
Cada contrato possui seu próprio percentual de garantia.

Passo 2 — Aplicação sobre a base
Base da rescisão × percentual do contrato.

Passo 3 — Limite pelo saldo devedor
O valor calculado não deve superar o saldo devedor informado para aquele contrato.

Passo 4 — Comparação com o TRCT
O sistema compara o valor calculado com o valor efetivamente descontado na rescisão.

Passo 5 — Total
Soma os quatro contratos e compara o percentual total com o limite informado.
Atenção:
Esta ferramenta é uma calculadora de conferência. A base efetivamente aplicável deve ser confirmada conforme os dados oficiais retornados para cada contrato e as regras vigentes no processamento da rescisão.

5. Ações

Observação:
Os valores exibidos são resultado de cálculo matemático a partir dos dados inseridos pelo usuário. A ferramenta não substitui a consulta dos dados oficiais do contrato, do saldo devedor atualizado ou das orientações aplicáveis ao processamento da rescisão.
